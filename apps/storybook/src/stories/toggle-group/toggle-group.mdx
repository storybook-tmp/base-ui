# Toggle Group

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Toggle } from '@base-ui/react/toggle';
import { ToggleGroup } from '@base-ui/react/toggle-group';

<ToggleGroup>
  <Toggle value="..." />
</ToggleGroup>;
```

| Part                                | Renders              | Purpose                                              | Optional?              |
| :---------------------------------- | :------------------- | :--------------------------------------------------- | :--------------------- |
| `ToggleGroup`                       | `<div role="group">` | Shared pressed-state context provider                | required               |
| `Toggle` (from the sibling package) | `<button>`           | Each group item (not a dedicated `ToggleGroup.Item`) | required (one or more) |

{/* END: anatomy */}

## Decision log

- **Introduced jointly with Toggle in [#763](https://github.com/mui/base-ui/pull/763)** (closing [#11](https://github.com/mui/base-ui/issues/11), [#31](https://github.com/mui/base-ui/issues/31)).
- **`#3971`**: Enable `Home`/`End` key navigation (closed [#3970](https://github.com/mui/base-ui/issues/3970)). Home/End was a reported gap rather than part of the original 2024 design, which explains the standalone-vs-Toolbar-hosted asymmetry above.
- **`#4488`**: Fix incorrect keyboard nav on cross axis.
- **`#4628`**: Remove invalid `aria-orientation` from `role="group"` element.
