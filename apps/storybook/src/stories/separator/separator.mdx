# Separator

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Separator } from '@base-ui/react/separator';

<Separator />;
```

Renders a single `<div>` with no sub-parts and no required children. The consumer sizes/styles it (width/height via CSS) to read visually as a line.

{/* END: anatomy */}

## Decision log

- **2024-09-27**: Separator ships ([#535](https://github.com/mui/base-ui/pull/535)), born inside the Menu Group and Separator work, initially modeled as `SeparatorRoot`.
- **~2024-12**: flattened to the current plain `Separator` API ([#997](https://github.com/mui/base-ui/pull/997)), part of a library-wide sweep to export single-part components without a Root.
- **2025-01-08**: vertical orientation added ([#1303](https://github.com/mui/base-ui/issues/1303) → [#1304](https://github.com/mui/base-ui/pull/1304)) for parity with comparable libraries.
- **2026-03-30**: data-attribute docs gap closed ([#4480](https://github.com/mui/base-ui/pull/4480)).
- **2026-04-22**: orientation-inversion confusion resolved as expected behavior ([#4647](https://github.com/mui/base-ui/issues/4647)).
