# Toggle

{/* BEGIN: when-to-use */}

## When to use

- A standalone two-state on/off control whose state doesn't need to submit with a form and doesn't need to announce as a native checkbox/switch: for example a "bold" toggle in a text editor, a single filter toggle, or a favorite/star button (the hero demo above).
- As the building block for [Toggle Group](?path=/docs/actions-toggle-group--docs): every item inside a group is an ordinary `<Toggle value="...">`.
- Inside a [Toolbar](?path=/docs/actions-toolbar--docs), composed via `Toolbar.Button render={<Toggle />}`.

## When not to use

- **A single-select-you-can't-clear semantic → [Radio Group](?path=/docs/form-inputs-radio--docs)**, not a single-mode Toggle Group. A single-select-you-can't-clear widget is a radio group; making a toggle announce as a radio would be semantically wrong ([#3525](https://github.com/mui/base-ui/issues/3525), open).
- **A value that must submit with a `<form>` or participate in native constraint validation → [Switch](?path=/docs/form-inputs-switch--docs)**. Toggle discards `form`/`type` (see below); it has no hidden-input form-participation machinery.
- **A binary immediate-effect setting with an on/off metaphor (not a pressed-button metaphor) → Switch.**
- **A single independent action, not a persisted state → [Button](?path=/docs/actions-button--docs)**, not Toggle.

{/* END: when-to-use */}

## Anatomy

```tsx
import { Toggle } from '@base-ui/react/toggle';

<Toggle />;
```

| Part     | Renders                                                  | Purpose                                                                | Optional? |
| :------- | :------------------------------------------------------- | :--------------------------------------------------------------------- | :-------- |
| `Toggle` | `<button>` (standalone) or via `CompositeItem` (grouped) | The single element: pressed state, `aria-pressed`, keyboard activation | required  |

## Related

- To capture a boolean **at submit time**, use [Checkbox](?path=/docs/form-inputs-checkbox--docs).
- For a boolean setting with **immediate effect** and an on/off metaphor, use [Switch](?path=/docs/form-inputs-switch--docs).
- To group related toggles with shared pressed-state bookkeeping, use [Toggle Group](?path=/docs/actions-toggle-group--docs).
