# Toggle

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Toggle } from '@base-ui/react/toggle';

<Toggle />;
```

| Part     | Renders                                                  | Purpose                                                                | Optional? |
| :------- | :------------------------------------------------------- | :--------------------------------------------------------------------- | :-------- |
| `Toggle` | `<button>` (standalone) or via `CompositeItem` (grouped) | The single element: pressed state, `aria-pressed`, keyboard activation | required  |

{/* END: anatomy */}

{/* BEGIN: do-dont */}

## Do / Don't

**Do**

- Give every standalone Toggle an accessible name (`aria-label` or visible text); there is no dedicated label part.

**Don't**

- Don't pass `form`/`type` expecting form participation. Both are silently discarded by design; reach for Switch or Checkbox instead.

{/* END: do-dont */}
