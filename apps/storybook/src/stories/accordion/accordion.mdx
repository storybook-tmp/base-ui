# Accordion

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Accordion } from '@base-ui/react/accordion';

<Accordion.Root>
  <Accordion.Item>
    <Accordion.Header>
      <Accordion.Trigger />
    </Accordion.Header>
    <Accordion.Panel />
  </Accordion.Item>
</Accordion.Root>;
```

| Part                | Renders    | Purpose                                       | Optional?          |
| :------------------ | :--------- | :-------------------------------------------- | :----------------- |
| `Accordion.Root`    | `<div>`    | Groups all parts of the accordion             | required           |
| `Accordion.Item`    | `<div>`    | Groups a header with its corresponding panel  | required, repeated |
| `Accordion.Header`  | `<h3>`     | A heading that labels the corresponding panel | required           |
| `Accordion.Trigger` | `<button>` | Opens and closes the corresponding panel      | required           |
| `Accordion.Panel`   | `<div>`    | The collapsible panel contents                | required           |

## Decision log — the APG-alignment removal

Two related PRs, merged the same day (2026-06-08), that removed behavior which had shipped since Accordion's 2024-10-30 launch ([#577](https://github.com/mui/base-ui/pull/577)):

- **[#4965](https://github.com/mui/base-ui/pull/4965): Align Accordion keyboard navigation with APG.** The Accordion APG pattern no longer recommends roving focus, as documented in [w3c/aria-practices#3434](https://github.com/w3c/aria-practices/pull/3434), so we removed roving focus from Accordion to align with the latest APG guidance. In its recent revisions, Accordion never used a `Composite`/roving-tabindex implementation to begin with. The PR formalizes the absence as intentional rather than a missing feature, and marks `orientation`/`loopFocus` as `@deprecated` for keyboard purposes.
- **[#4961](https://github.com/mui/base-ui/pull/4961): Remove region role from `Accordion.Root`.** In the WAI-ARIA accordion pattern, `region` is typically applied to accordion panels rather than the root container. `Accordion.Root` serves as a structural wrapper and has no accessible label of its own, so removing the region role better aligns with the APG guidance. `role="region"` already lived correctly on `Accordion.Panel`, so no functional gap resulted, only removal of a redundant/misplaced role on Root.

The removal is by design rather than a regression. Current W3C APG guidance dropped roving-focus arrow-key navigation from the Accordion pattern entirely, and we track that guidance rather than an older, more elaborate version some other libraries still implement.

- **2024-10-30**: Accordion ships ([#577](https://github.com/mui/base-ui/pull/577)), built from day one atop shared Collapsible hooks.
- **2025-beta.5**: `multiple` defaults to `false` ([#3141](https://github.com/mui/base-ui/pull/3141)), a deliberate breaking change.
- **2026-06-08**: APG alignment pair, [#4965](https://github.com/mui/base-ui/pull/4965) (roving-focus removal) and [#4961](https://github.com/mui/base-ui/pull/4961) (`role="region"` removal from Root).
