# Toolbar

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Toolbar } from '@base-ui/react/toolbar';

<Toolbar.Root>
  <Toolbar.Button />
  <Toolbar.Link />
  <Toolbar.Separator />
  <Toolbar.Group>
    <Toolbar.Button />
    <Toolbar.Button />
  </Toolbar.Group>
  <Toolbar.Input />
</Toolbar.Root>;
```

| Part                | Renders                  | Purpose                                              | Optional?                                      |
| :------------------ | :----------------------- | :--------------------------------------------------- | :--------------------------------------------- |
| `Toolbar.Root`      | `<div role="toolbar">`   | The single composite region                          | required                                       |
| `Toolbar.Button`    | `<button>`               | A button, or a trigger host via `render`             | optional (one or more typically)               |
| `Toolbar.Link`      | `<a>`                    | A link item; can never be disabled                   | optional                                       |
| `Toolbar.Input`     | `<input>`                | A native input integrating with toolbar keyboard nav | optional, at most one recommended, placed last |
| `Toolbar.Group`     | `<div role="group">`     | Groups items with a shared disabled cascade          | optional                                       |
| `Toolbar.Separator` | re-export of `Separator` | Visual divider, orientation auto-flipped             | optional                                       |

{/* END: anatomy */}

## Decision log

- **Introduced in [#1349](https://github.com/mui/base-ui/pull/1349)** (closing [#661](https://github.com/mui/base-ui/issues/661)): shipped with Root/Button/Input/Link/Group/Separator, `focusableWhenDisabled`, `orientation`, roving focus with `loop`, and a `cols` grid-layout prop; we deferred a `hotkey` prop to [#1454](https://github.com/mui/base-ui/issues/1454).
- **`#3133`**: Dropped the `cols` prop, a rare shipped-then-retracted API surface for this component (rationale not available beyond the commit subject).
- **`#2176`**: Set `disabled` attr on toolbar button when `focusableWhenDisabled={false}`.
- **`#4967`/`#4968`**: Do not forward `disabled` to the default toolbar button; fix disabled state and roving focus bugs. These two changes explain the asymmetric disabled-forwarding behavior above.

{/* END: history */}
