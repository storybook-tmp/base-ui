## Anatomy

```tsx
import { Autocomplete } from '@base-ui/react/autocomplete';

<Autocomplete.Root>
  <Autocomplete.InputGroup>
    <Autocomplete.Input />
    <Autocomplete.Trigger>
      <Autocomplete.Icon />
    </Autocomplete.Trigger>
    <Autocomplete.Clear />
    <Autocomplete.Value />
  </Autocomplete.InputGroup>
  <Autocomplete.Portal>
    <Autocomplete.Backdrop />
    <Autocomplete.Positioner>
      <Autocomplete.Popup>
        <Autocomplete.Arrow />
        <Autocomplete.Status />
        <Autocomplete.Empty />
        <Autocomplete.List>
          <Autocomplete.Row>
            <Autocomplete.Item />
          </Autocomplete.Row>
          <Autocomplete.Separator />
          <Autocomplete.Group>
            <Autocomplete.GroupLabel />
            <Autocomplete.Collection />
          </Autocomplete.Group>
        </Autocomplete.List>
      </Autocomplete.Popup>
    </Autocomplete.Positioner>
  </Autocomplete.Portal>
</Autocomplete.Root>;
```

| Part                                | Renders    | Purpose                                                                                                                                                                                   | Optional?            |
| :---------------------------------- | :--------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------- |
| `Autocomplete.Root`                 | no element | Groups all parts; owns the text value, filtering, and popup state                                                                                                                         | required             |
| `Autocomplete.Input`                | `<input>`  | The text input, **the interactive control**; wrap in a `<label>` or `Field`                                                                                                               | required in practice |
| `Autocomplete.InputGroup`           | `<div>`    | Wrapper for the input and its associated controls; carries the same state attributes as Trigger ([#3745](https://github.com/mui/base-ui/pull/3745))                                       | yes                  |
| `Autocomplete.Trigger`              | `<button>` | Opens the popup without typing; becomes the `role="combobox"` reference when the Input lives inside the popup ([#2973](https://github.com/mui/base-ui/pull/2973))                         | yes                  |
| `Autocomplete.Icon`                 | `<span>`   | Decorative icon (chevron/magnifier)                                                                                                                                                       | yes                  |
| `Autocomplete.Clear`                | `<button>` | Clears the input; deliberately not tabbable, one tab stop per field ([#3630](https://github.com/mui/base-ui/pull/3630))                                                                   | yes                  |
| `Autocomplete.Value`                | no element | Render-prop access to the live input text (used by the fuzzy story's Empty message)                                                                                                       | yes                  |
| `Autocomplete.Portal`               | `<div>`    | Moves the popup subtree to `<body>` (or `container`)                                                                                                                                      | required for popup   |
| `Autocomplete.Backdrop`             | `<div>`    | Styleable overlay beneath the popup                                                                                                                                                       | yes                  |
| `Autocomplete.Positioner`           | `<div>`    | Anchors the popup; owns `side`/`align`/`sideOffset`                                                                                                                                       | required for popup   |
| `Autocomplete.Popup`                | `<div>`    | Popup container: `role="presentation"`, or `role="dialog"` when the Input renders inside it ([#3213](https://github.com/mui/base-ui/pull/3213))                                           | required for popup   |
| `Autocomplete.List`                 | `<div>`    | `role="listbox"` (or `"grid"`); function-child render mode fed by `items`; hosts the composite so the Input can join outer composites ([#2883](https://github.com/mui/base-ui/pull/2883)) | required             |
| `Autocomplete.Item`                 | `<div>`    | `role="option"` (`gridcell` inside `Row`); **no `aria-selected`/`data-selected`**; nothing is ever selected ([#4409](https://github.com/mui/base-ui/pull/4409))                           | required             |
| `Autocomplete.Row`                  | `<div>`    | `role="row"` wrapper in `grid` mode; columns are inferred from it ([#2683](https://github.com/mui/base-ui/pull/2683))                                                                     | grid only            |
| `Autocomplete.Group` / `GroupLabel` | `<div>`    | Groups related items with an auto-associated label                                                                                                                                        | yes                  |
| `Autocomplete.Collection`           | no element | Re-renders the filtered subset inside each `Group`                                                                                                                                        | with groups          |
| `Autocomplete.Status`               | `<div>`    | `role="status"` polite live region (async/limit feedback); keep mounted, toggle its children                                                                                              | yes                  |
| `Autocomplete.Empty`                | `<div>`    | Renders children only when the list is empty; also a polite live region; keep mounted                                                                                                     | yes, recommended     |
| `Autocomplete.Separator`            | `<div>`    | Visual divider (re-exports the standalone `Separator`)                                                                                                                                    | yes                  |
| `Autocomplete.Arrow`                | `<div>`    | Arrow pointing at the anchor; rare for autocompletes                                                                                                                                      | yes                  |
| `Autocomplete.useFilter`            | hook       | `Intl.Collator`-based `contains`/`startsWith` matchers for your own filtering code                                                                                                        | yes                  |
| `Autocomplete.useFilteredItems`     | hook       | Reads the internally filtered items inside `Root`; the virtualization hook ([#3732](https://github.com/mui/base-ui/pull/3732))                                                            | yes                  |

## Do / Don't

**Do**

- Give the input an accessible name (a wrapping `<label>`, `Field.Label`, or `aria-label` for standalone search/command inputs); it's the consumer half of the a11y contract ([#4949](https://github.com/mui/base-ui/pull/4949)).
- Pass `filter={null}` when your server already filters, because the internal filter would otherwise re-filter the results ([#4196](https://github.com/mui/base-ui/issues/4196)).
- Render `Empty` inside dialogs, because Escape bubbles to the parent popup when the list is empty and no `Empty` is rendered ([#2935](https://github.com/mui/base-ui/pull/2935)).
- Include a submit button when using `submitOnItemClick`, because native HTML won't submit a form containing only the hidden input ([#3018](https://github.com/mui/base-ui/pull/3018)).
- Keep `Status`/`Empty` mounted and toggle their children, because removing the live region breaks screen-reader announcements (part JSDoc).

**Don't**

- Don't expect users to press Enter twice to submit free text. Enter with no highlight submits since [#2700](https://github.com/mui/base-ui/pull/2700); if it doesn't, check that nothing is auto-highlighted.
- Don't fight the closed-popup Escape clear with input hacks; cancel the `escape-key` reason in `onValueChange` instead ([#4245](https://github.com/mui/base-ui/issues/4245)).
- Don't `.map` group objects manually; use `Group items` + `Collection`, or per-group filtering silently breaks (docs Grouped).
- Don't render 1,000+ raw items: memoize up to ~1,000, then virtualize; mount cost dominates beyond that ([#5062](https://github.com/mui/base-ui/pull/5062), [#3068](https://github.com/mui/base-ui/pull/3068)).
- Don't rely on a highlight reset when swapping item sets mid-flow; there's no public API to reset it yet. Temporarily empty `items` as a workaround ([#4745](https://github.com/mui/base-ui/issues/4745), open).
- Don't forget `[data-disabled]` styling: disabled items are still highlightable for now ([#4666](https://github.com/mui/base-ui/issues/4666), open).
