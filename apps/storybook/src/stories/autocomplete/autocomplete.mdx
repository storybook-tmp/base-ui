## Anatomy

```tsx
import { Autocomplete } from '@base-ui/react/autocomplete';

<Autocomplete.Root>
  <Autocomplete.InputGroup>
    <Autocomplete.Input />
    <Autocomplete.Trigger>
      <Autocomplete.Icon />
    </Autocomplete.Trigger>
    <Autocomplete.Clear />
    <Autocomplete.Value />
  </Autocomplete.InputGroup>
  <Autocomplete.Portal>
    <Autocomplete.Backdrop />
    <Autocomplete.Positioner>
      <Autocomplete.Popup>
        <Autocomplete.Arrow />
        <Autocomplete.Status />
        <Autocomplete.Empty />
        <Autocomplete.List>
          <Autocomplete.Row>
            <Autocomplete.Item />
          </Autocomplete.Row>
          <Autocomplete.Separator />
          <Autocomplete.Group>
            <Autocomplete.GroupLabel />
            <Autocomplete.Collection />
          </Autocomplete.Group>
        </Autocomplete.List>
      </Autocomplete.Popup>
    </Autocomplete.Positioner>
  </Autocomplete.Portal>
</Autocomplete.Root>;
```

| Part                                | Renders    | Purpose                                                                                                                                                                                   | Optional?            |
| :---------------------------------- | :--------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------- |
| `Autocomplete.Root`                 | no element | Groups all parts; owns the text value, filtering, and popup state                                                                                                                         | required             |
| `Autocomplete.Input`                | `<input>`  | The text input, **the interactive control**; wrap in a `<label>` or `Field`                                                                                                               | required in practice |
| `Autocomplete.InputGroup`           | `<div>`    | Wrapper for the input and its associated controls; carries the same state attributes as Trigger ([#3745](https://github.com/mui/base-ui/pull/3745))                                       | yes                  |
| `Autocomplete.Trigger`              | `<button>` | Opens the popup without typing; becomes the `role="combobox"` reference when the Input lives inside the popup ([#2973](https://github.com/mui/base-ui/pull/2973))                         | yes                  |
| `Autocomplete.Icon`                 | `<span>`   | Decorative icon (chevron/magnifier)                                                                                                                                                       | yes                  |
| `Autocomplete.Clear`                | `<button>` | Clears the input; deliberately not tabbable, one tab stop per field ([#3630](https://github.com/mui/base-ui/pull/3630))                                                                   | yes                  |
| `Autocomplete.Value`                | no element | Render-prop access to the live input text (used by the fuzzy story's Empty message)                                                                                                       | yes                  |
| `Autocomplete.Portal`               | `<div>`    | Moves the popup subtree to `<body>` (or `container`)                                                                                                                                      | required for popup   |
| `Autocomplete.Backdrop`             | `<div>`    | Styleable overlay beneath the popup                                                                                                                                                       | yes                  |
| `Autocomplete.Positioner`           | `<div>`    | Anchors the popup; owns `side`/`align`/`sideOffset`                                                                                                                                       | required for popup   |
| `Autocomplete.Popup`                | `<div>`    | Popup container: `role="presentation"`, or `role="dialog"` when the Input renders inside it ([#3213](https://github.com/mui/base-ui/pull/3213))                                           | required for popup   |
| `Autocomplete.List`                 | `<div>`    | `role="listbox"` (or `"grid"`); function-child render mode fed by `items`; hosts the composite so the Input can join outer composites ([#2883](https://github.com/mui/base-ui/pull/2883)) | required             |
| `Autocomplete.Item`                 | `<div>`    | `role="option"` (`gridcell` inside `Row`); **no `aria-selected`/`data-selected`**; nothing is ever selected ([#4409](https://github.com/mui/base-ui/pull/4409))                           | required             |
| `Autocomplete.Row`                  | `<div>`    | `role="row"` wrapper in `grid` mode; columns are inferred from it ([#2683](https://github.com/mui/base-ui/pull/2683))                                                                     | grid only            |
| `Autocomplete.Group` / `GroupLabel` | `<div>`    | Groups related items with an auto-associated label                                                                                                                                        | yes                  |
| `Autocomplete.Collection`           | no element | Re-renders the filtered subset inside each `Group`                                                                                                                                        | with groups          |
| `Autocomplete.Status`               | `<div>`    | `role="status"` polite live region (async/limit feedback); keep mounted, toggle its children                                                                                              | yes                  |
| `Autocomplete.Empty`                | `<div>`    | Renders children only when the list is empty; also a polite live region; keep mounted                                                                                                     | yes, recommended     |
| `Autocomplete.Separator`            | `<div>`    | Visual divider (re-exports the standalone `Separator`)                                                                                                                                    | yes                  |
| `Autocomplete.Arrow`                | `<div>`    | Arrow pointing at the anchor; rare for autocompletes                                                                                                                                      | yes                  |
| `Autocomplete.useFilter`            | hook       | `Intl.Collator`-based `contains`/`startsWith` matchers for your own filtering code                                                                                                        | yes                  |
| `Autocomplete.useFilteredItems`     | hook       | Reads the internally filtered items inside `Root`; the virtualization hook ([#3732](https://github.com/mui/base-ui/pull/3732))                                                            | yes                  |

## Decision log

- **2025-09-03: Autocomplete ships as its own component** ([#2105](https://github.com/mui/base-ui/pull/2105), closing [#222](https://github.com/mui/base-ui/issues/222)): a mid-PR pivot split the monolithic Combobox into Combobox (restricted input) / Autocomplete (`selectionMode="none"`, free text) / a deferred `FilterableMenu`, because Combobox was taking on too many roles and becoming overly monolithic. The `value` semantics follow from the split: for Autocomplete, `value` refers to the input text.
- **2025-09 (beta.4): Enter submits when nothing is highlighted** ([#2700](https://github.com/mui/base-ui/pull/2700), closing [#2686](https://github.com/mui/base-ui/issues/2686)): we treated the old behavior as a bug; Google Search submits this way.
- **beta.4: `cols` → `grid`** ([#2683](https://github.com/mui/base-ui/pull/2683), breaking): columns inferred from `Row`. **`CompositeList` moves onto `List`** ([#2883](https://github.com/mui/base-ui/pull/2883)) so the Input can join outer composite widgets.
- **2025-10 (beta.5): `alwaysSubmitOnEnter` → `submitOnItemClick`** ([#3018](https://github.com/mui/base-ui/pull/3018), breaking): submission belongs to item _click_ (pointer + Enter); documents the hidden-input/submit-button constraint.
- **beta.5: highlight-control trio** `autoHighlight: 'always'`, `keepHighlight`, `highlightItemOnHover` ([#2976](https://github.com/mui/base-ui/pull/2976)), the command-palette enablers.
- **2025-11: Escape bubbling rule** ([#2935](https://github.com/mui/base-ui/pull/2935)); **`role="dialog"` popup when the input is inside** ([#3213](https://github.com/mui/base-ui/pull/3213)); the outside trigger becomes the combobox reference ([#2973](https://github.com/mui/base-ui/pull/2973)).
- **2026-01 (v1.1.0)**: `InputGroup` part ([#3745](https://github.com/mui/base-ui/pull/3745)); `loopFocus` ([#3592](https://github.com/mui/base-ui/pull/3592)); `useFilteredItems` hook ([#3732](https://github.com/mui/base-ui/pull/3732)).
- **2026-02 (v1.2.0): filtering correctness sweep** ([#3936](https://github.com/mui/base-ui/pull/3936), [#3862](https://github.com/mui/base-ui/pull/3862), [#3945](https://github.com/mui/base-ui/pull/3945)); regression `filter={null}` ignored ([#4196](https://github.com/mui/base-ui/issues/4196)) fixed in [#4117](https://github.com/mui/base-ui/pull/4117).
- **2026-03/04 (v1.4.0): Autocomplete owns its exports and docs** ([#4409](https://github.com/mui/base-ui/pull/4409)): own part files, JSDoc, data-attribute enums; `data-selected` removed from Item's public contract. Native FormData for popup-rendered inputs ([#4725](https://github.com/mui/base-ui/pull/4725)).
- **2026-05/06: a11y & docs wave**: command-palette demo a11y ([#4949](https://github.com/mui/base-ui/pull/4949), closing [#4247](https://github.com/mui/base-ui/issues/4247)/[#4248](https://github.com/mui/base-ui/issues/4248)); `inline`-requires-`open` documented ([#5069](https://github.com/mui/base-ui/pull/5069)); memoization guidance ([#5062](https://github.com/mui/base-ui/pull/5062)).

## Known issues & open questions

- [#4408](https://github.com/mui/base-ui/issues/4408): transition flicker on input clear when no items match (open).
- [#2933](https://github.com/mui/base-ui/issues/2933): no built-in "default items when no results"; userland via external filtering (open).
- [#4745](https://github.com/mui/base-ui/issues/4745): no public API to reset the highlight when swapping item sets (open; workaround: temporarily empty `items`).
- [#4666](https://github.com/mui/base-ui/issues/4666): disabled items are highlightable; we agree they shouldn't be (open).
- [#2669](https://github.com/mui/base-ui/issues/2669): inline completion doesn't select the appended text like Chrome (open).
- [#3853](https://github.com/mui/base-ui/issues/3853): `itemToStringValue`/`Item value` TypeScript inference docs flagged confusing (open).
- [#4157](https://github.com/mui/base-ui/issues/4157): searchable menu with submenus fits no component; a future component may cover it (open).
- [#2854](https://github.com/mui/base-ui/issues/2854): popups inside third-party overlays (Radix dialogs etc.) need `Portal container` for pointer-events interop.
- [#4182](https://github.com/mui/base-ui/issues/4182): the command-palette demo's focus indicator relies on color alone (open).
- [#4183](https://github.com/mui/base-ui/issues/4183): the command palette lacks a persistently visible label (open).
- [#5146](https://github.com/mui/base-ui/issues/5146): no vim-style Ctrl+N/P navigation (open).
