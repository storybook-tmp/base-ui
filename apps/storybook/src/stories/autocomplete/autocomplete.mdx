# Autocomplete

## When to use

- Free-form text where suggestions help but any value is legal: search fields, tag/query inputs. The input can have any value, as in Google Search ([#2105](https://github.com/mui/base-ui/pull/2105)).
- Filterable command pickers / command palettes: the recommended recipe for the deferred `FilterableMenu` role ([#4157](https://github.com/mui/base-ui/issues/4157), [#2817](https://github.com/mui/base-ui/issues/2817)). The input filters command items that perform an action when clicked.
- Inline autocompletion UIs (`mode="both"`/`"inline"`): autofill the input with the highlighted item while arrowing, Chrome-omnibox style ([#2669](https://github.com/mui/base-ui/issues/2669)).
- Async/server-backed suggestions: a first-class pattern of controlled `value` + `filter={null}` + `Status` + AbortController (docs "Async search").
- Large suggestion sets: `limit`, memoized items ([#5062](https://github.com/mui/base-ui/pull/5062)), and virtualization via `useFilteredItems` ([#3068](https://github.com/mui/base-ui/pull/3068)).

## When not to use

The pickers boundary in one line: _free-form text → Autocomplete; visible filter input over a fixed set → [Combobox](?path=/docs/form-inputs-combobox--docs); button + predefined values → [Select](?path=/docs/form-inputs-select--docs); popup that performs actions without filtering → Menu_.

- **Selection must be remembered or restricted to the list → [Combobox](?path=/docs/form-inputs-combobox--docs)**: use Combobox when the selection should be remembered and the input value cannot be custom. Autocomplete has no selection state at all; it is the shared `AriaCombobox` engine fixed to `selectionMode="none"`.
- **No text input rendered → [Select](?path=/docs/form-inputs-select--docs)**: use Select when no input is being rendered; Autocomplete without its Input is meaningless since the input _is_ the control.
- **Dropdown of actions without filtering → Menu**. A searchable menu _with submenus_ fits no component yet; Autocomplete would need `SubmenuRoot` parts, and a separate component with different roles and behavior is probably cleanest ([#4157](https://github.com/mui/base-ui/issues/4157), open). Filterable flat command lists belong here; see the command-palette recipe below.
- **Multi-value tokenized entry → Combobox `multiple` + Chips**: Autocomplete's value is one string; it has no `multiple`.
- **Plain text field without suggestions → Input/Field**: the popup machinery is pure overhead then.

## Anatomy

```tsx
import { Autocomplete } from '@base-ui/react/autocomplete';

<Autocomplete.Root>
  <Autocomplete.InputGroup>
    <Autocomplete.Input />
    <Autocomplete.Trigger>
      <Autocomplete.Icon />
    </Autocomplete.Trigger>
    <Autocomplete.Clear />
    <Autocomplete.Value />
  </Autocomplete.InputGroup>
  <Autocomplete.Portal>
    <Autocomplete.Backdrop />
    <Autocomplete.Positioner>
      <Autocomplete.Popup>
        <Autocomplete.Arrow />
        <Autocomplete.Status />
        <Autocomplete.Empty />
        <Autocomplete.List>
          <Autocomplete.Row>
            <Autocomplete.Item />
          </Autocomplete.Row>
          <Autocomplete.Separator />
          <Autocomplete.Group>
            <Autocomplete.GroupLabel />
            <Autocomplete.Collection />
          </Autocomplete.Group>
        </Autocomplete.List>
      </Autocomplete.Popup>
    </Autocomplete.Positioner>
  </Autocomplete.Portal>
</Autocomplete.Root>;
```

| Part                                | Renders    | Purpose                                                                                                                                                                                   | Optional?            |
| :---------------------------------- | :--------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------- |
| `Autocomplete.Root`                 | no element | Groups all parts; owns the text value, filtering, and popup state                                                                                                                         | required             |
| `Autocomplete.Input`                | `<input>`  | The text input, **the interactive control**; wrap in a `<label>` or `Field`                                                                                                               | required in practice |
| `Autocomplete.InputGroup`           | `<div>`    | Wrapper for the input and its associated controls; carries the same state attributes as Trigger ([#3745](https://github.com/mui/base-ui/pull/3745))                                       | yes                  |
| `Autocomplete.Trigger`              | `<button>` | Opens the popup without typing; becomes the `role="combobox"` reference when the Input lives inside the popup ([#2973](https://github.com/mui/base-ui/pull/2973))                         | yes                  |
| `Autocomplete.Icon`                 | `<span>`   | Decorative icon (chevron/magnifier)                                                                                                                                                       | yes                  |
| `Autocomplete.Clear`                | `<button>` | Clears the input; deliberately not tabbable, one tab stop per field ([#3630](https://github.com/mui/base-ui/pull/3630))                                                                   | yes                  |
| `Autocomplete.Value`                | no element | Render-prop access to the live input text (used by the fuzzy story's Empty message)                                                                                                       | yes                  |
| `Autocomplete.Portal`               | `<div>`    | Moves the popup subtree to `<body>` (or `container`)                                                                                                                                      | required for popup   |
| `Autocomplete.Backdrop`             | `<div>`    | Styleable overlay beneath the popup                                                                                                                                                       | yes                  |
| `Autocomplete.Positioner`           | `<div>`    | Anchors the popup; owns `side`/`align`/`sideOffset`                                                                                                                                       | required for popup   |
| `Autocomplete.Popup`                | `<div>`    | Popup container: `role="presentation"`, or `role="dialog"` when the Input renders inside it ([#3213](https://github.com/mui/base-ui/pull/3213))                                           | required for popup   |
| `Autocomplete.List`                 | `<div>`    | `role="listbox"` (or `"grid"`); function-child render mode fed by `items`; hosts the composite so the Input can join outer composites ([#2883](https://github.com/mui/base-ui/pull/2883)) | required             |
| `Autocomplete.Item`                 | `<div>`    | `role="option"` (`gridcell` inside `Row`); **no `aria-selected`/`data-selected`**; nothing is ever selected ([#4409](https://github.com/mui/base-ui/pull/4409))                           | required             |
| `Autocomplete.Row`                  | `<div>`    | `role="row"` wrapper in `grid` mode; columns are inferred from it ([#2683](https://github.com/mui/base-ui/pull/2683))                                                                     | grid only            |
| `Autocomplete.Group` / `GroupLabel` | `<div>`    | Groups related items with an auto-associated label                                                                                                                                        | yes                  |
| `Autocomplete.Collection`           | no element | Re-renders the filtered subset inside each `Group`                                                                                                                                        | with groups          |
| `Autocomplete.Status`               | `<div>`    | `role="status"` polite live region (async/limit feedback); keep mounted, toggle its children                                                                                              | yes                  |
| `Autocomplete.Empty`                | `<div>`    | Renders children only when the list is empty; also a polite live region; keep mounted                                                                                                     | yes, recommended     |
| `Autocomplete.Separator`            | `<div>`    | Visual divider (re-exports the standalone `Separator`)                                                                                                                                    | yes                  |
| `Autocomplete.Arrow`                | `<div>`    | Arrow pointing at the anchor; rare for autocompletes                                                                                                                                      | yes                  |
| `Autocomplete.useFilter`            | hook       | `Intl.Collator`-based `contains`/`startsWith` matchers for your own filtering code                                                                                                        | yes                  |
| `Autocomplete.useFilteredItems`     | hook       | Reads the internally filtered items inside `Root`; the virtualization hook ([#3732](https://github.com/mui/base-ui/pull/3732))                                                            | yes                  |

## Related

- To **remember a selection** restricted to the list, use [Combobox](?path=/docs/form-inputs-combobox--docs).
- To pick a predefined value with **no text input**, use [Select](?path=/docs/form-inputs-select--docs).
- To show a dropdown of **actions without filtering**, use Menu.
- To add labels, descriptions, and validation, wrap in Field inside a Form (see the `InFieldWithValidation` story).
- To build a **command palette**, pair with Dialog (see the `CommandPalette` story).
