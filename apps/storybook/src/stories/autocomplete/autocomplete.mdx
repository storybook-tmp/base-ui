## Anatomy

```tsx
import { Autocomplete } from '@base-ui/react/autocomplete';

<Autocomplete.Root>
  <Autocomplete.InputGroup>
    <Autocomplete.Input />
    <Autocomplete.Trigger>
      <Autocomplete.Icon />
    </Autocomplete.Trigger>
    <Autocomplete.Clear />
    <Autocomplete.Value />
  </Autocomplete.InputGroup>
  <Autocomplete.Portal>
    <Autocomplete.Backdrop />
    <Autocomplete.Positioner>
      <Autocomplete.Popup>
        <Autocomplete.Arrow />
        <Autocomplete.Status />
        <Autocomplete.Empty />
        <Autocomplete.List>
          <Autocomplete.Row>
            <Autocomplete.Item />
          </Autocomplete.Row>
          <Autocomplete.Separator />
          <Autocomplete.Group>
            <Autocomplete.GroupLabel />
            <Autocomplete.Collection />
          </Autocomplete.Group>
        </Autocomplete.List>
      </Autocomplete.Popup>
    </Autocomplete.Positioner>
  </Autocomplete.Portal>
</Autocomplete.Root>;
```

| Part                                | Renders    | Purpose                                                                                                                                                                                   | Optional?            |
| :---------------------------------- | :--------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------- |
| `Autocomplete.Root`                 | no element | Groups all parts; owns the text value, filtering, and popup state                                                                                                                         | required             |
| `Autocomplete.Input`                | `<input>`  | The text input, **the interactive control**; wrap in a `<label>` or `Field`                                                                                                               | required in practice |
| `Autocomplete.InputGroup`           | `<div>`    | Wrapper for the input and its associated controls; carries the same state attributes as Trigger ([#3745](https://github.com/mui/base-ui/pull/3745))                                       | yes                  |
| `Autocomplete.Trigger`              | `<button>` | Opens the popup without typing; becomes the `role="combobox"` reference when the Input lives inside the popup ([#2973](https://github.com/mui/base-ui/pull/2973))                         | yes                  |
| `Autocomplete.Icon`                 | `<span>`   | Decorative icon (chevron/magnifier)                                                                                                                                                       | yes                  |
| `Autocomplete.Clear`                | `<button>` | Clears the input; deliberately not tabbable, one tab stop per field ([#3630](https://github.com/mui/base-ui/pull/3630))                                                                   | yes                  |
| `Autocomplete.Value`                | no element | Render-prop access to the live input text (used by the fuzzy story's Empty message)                                                                                                       | yes                  |
| `Autocomplete.Portal`               | `<div>`    | Moves the popup subtree to `<body>` (or `container`)                                                                                                                                      | required for popup   |
| `Autocomplete.Backdrop`             | `<div>`    | Styleable overlay beneath the popup                                                                                                                                                       | yes                  |
| `Autocomplete.Positioner`           | `<div>`    | Anchors the popup; owns `side`/`align`/`sideOffset`                                                                                                                                       | required for popup   |
| `Autocomplete.Popup`                | `<div>`    | Popup container: `role="presentation"`, or `role="dialog"` when the Input renders inside it ([#3213](https://github.com/mui/base-ui/pull/3213))                                           | required for popup   |
| `Autocomplete.List`                 | `<div>`    | `role="listbox"` (or `"grid"`); function-child render mode fed by `items`; hosts the composite so the Input can join outer composites ([#2883](https://github.com/mui/base-ui/pull/2883)) | required             |
| `Autocomplete.Item`                 | `<div>`    | `role="option"` (`gridcell` inside `Row`); **no `aria-selected`/`data-selected`**; nothing is ever selected ([#4409](https://github.com/mui/base-ui/pull/4409))                           | required             |
| `Autocomplete.Row`                  | `<div>`    | `role="row"` wrapper in `grid` mode; columns are inferred from it ([#2683](https://github.com/mui/base-ui/pull/2683))                                                                     | grid only            |
| `Autocomplete.Group` / `GroupLabel` | `<div>`    | Groups related items with an auto-associated label                                                                                                                                        | yes                  |
| `Autocomplete.Collection`           | no element | Re-renders the filtered subset inside each `Group`                                                                                                                                        | with groups          |
| `Autocomplete.Status`               | `<div>`    | `role="status"` polite live region (async/limit feedback); keep mounted, toggle its children                                                                                              | yes                  |
| `Autocomplete.Empty`                | `<div>`    | Renders children only when the list is empty; also a polite live region; keep mounted                                                                                                     | yes, recommended     |
| `Autocomplete.Separator`            | `<div>`    | Visual divider (re-exports the standalone `Separator`)                                                                                                                                    | yes                  |
| `Autocomplete.Arrow`                | `<div>`    | Arrow pointing at the anchor; rare for autocompletes                                                                                                                                      | yes                  |
| `Autocomplete.useFilter`            | hook       | `Intl.Collator`-based `contains`/`startsWith` matchers for your own filtering code                                                                                                        | yes                  |
| `Autocomplete.useFilteredItems`     | hook       | Reads the internally filtered items inside `Root`; the virtualization hook ([#3732](https://github.com/mui/base-ui/pull/3732))                                                            | yes                  |

## Keyboard & screen reader

Pattern: [APG editable combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) with list/inline autocomplete per `mode`.

| Key                     | Context                | Action                                                                                                                                                                                                                                                                                       |
| :---------------------- | :--------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Printable characters    | any                    | Edits text; opens the popup; filters in `list`/`both` modes                                                                                                                                                                                                                                  |
| `ArrowDown` / `ArrowUp` | closed                 | Opens the popup; with `autoHighlight`, `ArrowDown` highlights the first item                                                                                                                                                                                                                 |
| `ArrowDown` / `ArrowUp` | open                   | Moves the virtual highlight (loops per `loopFocus`, [#3592](https://github.com/mui/base-ui/pull/3592)); in `both`/`inline` modes temporarily writes the highlighted item into the input                                                                                                      |
| `Enter`                 | open, item highlighted | "Clicks" the item: fills the input, fires `Item.onClick`, closes; does **not** submit the form unless `submitOnItemClick` ([#3018](https://github.com/mui/base-ui/pull/3018))                                                                                                                |
| `Enter`                 | open, no highlight     | Closes the popup and allows native form submission of the typed text ([#2700](https://github.com/mui/base-ui/pull/2700))                                                                                                                                                                     |
| `Escape`                | open                   | Closes the popup; the input keeps focus and its text ([#4240](https://github.com/mui/base-ui/issues/4240))                                                                                                                                                                                   |
| `Escape`                | closed                 | Clears the input (Chrome-omnibox parity); cancellable via `onValueChange` reason `escape-key` ([#4245](https://github.com/mui/base-ui/issues/4245)); bubbles to parent popups only if already clear, `inline`, or no `Empty` is rendered ([#2935](https://github.com/mui/base-ui/pull/2935)) |
| `Home` / `End`          | open                   | Moves the input **caret**, not the highlight; text editing wins ([#2928](https://github.com/mui/base-ui/pull/2928))                                                                                                                                                                          |
| `Tab`                   | open                   | Closes the popup and moves focus on; `Clear`/`Trigger` are not tab stops ([#3630](https://github.com/mui/base-ui/pull/3630))                                                                                                                                                                 |

- **ARIA managed for you**: Input gets `role="combobox"`, `aria-expanded`, `aria-haspopup="listbox"` (`"grid"` in grid mode), `aria-controls` while open, `aria-autocomplete={mode}`, `aria-activedescendant` (virtual focus), plus DOM hygiene (`autoComplete="off"`, `spellCheck=false`, `autoCorrect="off"`, `autoCapitalize="none"`). Popup gets `role="presentation"`, or `role="dialog"` when the Input is inside. List gets `role="listbox"`/`role="grid"`. Item gets `role="option"`/`gridcell`, **no `aria-selected`** ([#4409](https://github.com/mui/base-ui/pull/4409)). Status/Empty get `role="status"`, `aria-live="polite"`, `aria-atomic`, with the initial announcement handled via a mutation trick ([#4181](https://github.com/mui/base-ui/issues/4181)).
- **Screen reader**: typing announces filtered results via the listbox and any `Status`/`Empty` text; arrowing announces options through `aria-activedescendant` without moving DOM focus.
- **You must provide**: an accessible name (a `<label>`, `Field.Label`, or `aria-label` on the Input for standalone search/command inputs, [#4949](https://github.com/mui/base-ui/pull/4949)), plus visible `:focus-visible` styling and highlight contrast that doesn't rely on color alone ([#4182](https://github.com/mui/base-ui/issues/4182)).
