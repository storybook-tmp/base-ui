## Decision log

- **Pre-[#2225](https://github.com/mui/base-ui/issues/2225): initially rejected.** A headless `<button>` primitive was proposed and rejected under our scope test: ship a primitive only where (a) HTML lacks the functionality, (b) the element can't be styled, or (c) no good HTML primitive exists. A plain `<button>` fails all three, so by that test Button should not exist.
- **Reversed and merged in [#2363](https://github.com/mui/base-ui/pull/2363)** (closing [#2225](https://github.com/mui/base-ui/issues/2225), which itself traces to [#2138](https://github.com/mui/base-ui/issues/2138)). We overrode the scope test for accessibility reasons: `focusableWhenDisabled` (native `disabled` removes an element from the accessibility tree and tab order entirely, hiding loading/pending buttons from assistive technology), Enter/Space activation normalization on non-native tags, and browser-bug patching. Press/pointer-event normalization was explicitly scoped out and is tracked separately as [#1726](https://github.com/mui/base-ui/issues/1726). Button exists for these a11y affordances, not as a styling convenience.
- **`#3643`**: Remove discriminated props union (API simplification, post-1.0 minor).
- **`#3929`**: Improve dev warnings (shared with Field).
