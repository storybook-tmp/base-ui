# Avatar

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Avatar } from '@base-ui/react/avatar';

<Avatar.Root>
  <Avatar.Image src="" />
  <Avatar.Fallback>LT</Avatar.Fallback>
</Avatar.Root>;
```

| Part              | Renders  | Purpose                                                         | Optional?                                                          |
| :---------------- | :------- | :-------------------------------------------------------------- | :----------------------------------------------------------------- |
| `Avatar.Root`     | `<span>` | Container; owns the shared `imageLoadingStatus` context         | required                                                           |
| `Avatar.Image`    | `<img>`  | The image; only mounts once loading resolves to `loaded`        | yes; `Root` alone with text children is a valid "no photo" pattern |
| `Avatar.Fallback` | `<span>` | Rendered when the image fails to load, is loading, or is absent | yes; nothing shows in its place if omitted                         |

{/* END: anatomy */}

## Decision log

- **2025-01-20 → 2025-02-04**: Avatar ships (issue [#1347](https://github.com/mui/base-ui/issues/1347) → PR [#1210](https://github.com/mui/base-ui/pull/1210)), a community contribution by @acomanescu, referencing Radix UI's Avatar.
- **2026-02-11**: transition attributes added, `data-starting-style`/`data-ending-style` ([#3939](https://github.com/mui/base-ui/pull/3939)).
- **2026-02-16**: premature-mount bug fixed: Image no longer mounts before fully loaded ([#4110](https://github.com/mui/base-ui/pull/4110)).
- **2026-03**: community `aria-hidden`-by-default proposal for Fallback closed without merging ([#3095](https://github.com/mui/base-ui/pull/3095)).
- **2026-04-09**: cached-image flash fix: `image.complete` fast path added ([#4469](https://github.com/mui/base-ui/pull/4469), addressing still-open [#4468](https://github.com/mui/base-ui/issues/4468)).
- **2026-07-02**: fallback `delay={0}` default clarified to mean immediate, no wait ([#5147](https://github.com/mui/base-ui/pull/5147)).

{/* END: history */}

## Known issues & open questions

- [#4468](https://github.com/mui/base-ui/issues/4468) (open): fallback still flashes for cached images on SSR hydration in measurable, framework-dependent durations, despite the cached-image fast path.
- [#2597](https://github.com/mui/base-ui/issues/2597) (open): no lazy-loading support, an architectural consequence of the off-DOM probe design.
- **`alt` guidance gap**: a known gap in our docs with no tracking issue yet; neither hero demo sets `alt`, and the docs give no decorative-vs-informative rule.
