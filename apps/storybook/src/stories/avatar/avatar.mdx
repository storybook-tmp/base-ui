# Avatar

{/* BEGIN: when-to-use */}

## When to use

- User profile pictures with a graceful fallback (initials or icon) when no image is set or the image fails to load.
- Identity display in lists/headers/chat UIs.
- Showing initials-as-placeholder when a photo isn't available; both hero avatars above default to this.
- Responsive/high-DPI image scenarios: `Avatar.Image` forwards native `srcSet`/`sizes`/`crossOrigin`/`referrerPolicy`, and the loading probe respects them too.

## When not to use

- For a purely decorative image with no need for load-state fallback, a plain `<img>` is simpler. Avatar's value is the loading-status state machine.
- For a numeric or measurement display (e.g. a completion ring, a presence dot), that's [Progress](?path=/docs/status-display-progress--docs) or [Meter](?path=/docs/status-display-meter--docs)'s job. Avatar has no numeric-measurement API; a presence indicator would need to be composed alongside it.
- For lazy-loaded image grids at scale, the off-DOM probe design forecloses `loading="lazy"`, a known open gap ([#2597](https://github.com/mui/base-ui/issues/2597)).

{/* END: when-to-use */}

## Anatomy

```tsx
import { Avatar } from '@base-ui/react/avatar';

<Avatar.Root>
  <Avatar.Image src="" />
  <Avatar.Fallback>LT</Avatar.Fallback>
</Avatar.Root>;
```

| Part              | Renders  | Purpose                                                         | Optional?                                                          |
| :---------------- | :------- | :-------------------------------------------------------------- | :----------------------------------------------------------------- |
| `Avatar.Root`     | `<span>` | Container; owns the shared `imageLoadingStatus` context         | required                                                           |
| `Avatar.Image`    | `<img>`  | The image; only mounts once loading resolves to `loaded`        | yes; `Root` alone with text children is a valid "no photo" pattern |
| `Avatar.Fallback` | `<span>` | Rendered when the image fails to load, is loading, or is absent | yes; nothing shows in its place if omitted                         |

{/* END: anatomy */}
