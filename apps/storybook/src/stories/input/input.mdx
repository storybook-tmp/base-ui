# Input

{/* BEGIN: general */}
A native input element that automatically works with [Field](?path=/docs/form-inputs-field--docs).

- **Import:** `import { Input } from '@base-ui/react/input';`
- **Parts:** 1, a single node with no compound namespace (`Input`, not `Input.Root`).
- **Status:** Stable, no version-tag. A rename of the pre-existing `TextInput` (`288bbdda`, [#932](https://github.com/mui/base-ui/issues/932)); before the Base UI repo existed, the lineage traces to `@mui/base`'s `Input`/`InputBase`.
- **ARIA pattern:** none of its own; a native `<input>`, plus whatever `Field` supplies when nested inside it.

<Canvas of={InputStories.Hero} />

> **Input is [Field.Control](?path=/docs/form-inputs-field--docs) under a shorter name.** For complete documentation of Input (the interaction-state machine, validation lifecycle, controlled/uncontrolled contract, disabled semantics), read the [Field page](?path=/docs/form-inputs-field--docs); this page covers only what's specific to `Input` itself.

## Features

- **A native `<input>`, wired automatically**: nested inside `Field.Root`, it registers with the shared `LabelableProvider` and interaction-state machine with zero wiring props.
- **Works standalone, too**: outside any `Field`/`Form` tree, `Input` degrades to a plain native `<input>` plus `onValueChange`; only `data-disabled` remains a meaningful attribute.
- **Zero styling contract of its own**: Input exposes no CSS variables, and every data attribute applies only when wrapped in `Field.Root` (they're Field's, restated).

## Anatomy

```tsx
import { Input } from '@base-ui/react/input';

<Input />;
```

A single node with no children slots: the simplest anatomy in the library, alongside Button/Toggle/Separator.
