# Combobox

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Combobox } from '@base-ui/react/combobox';

<Combobox.Root>
  <Combobox.Label />
  <Combobox.InputGroup>
    <Combobox.Input />
    <Combobox.Trigger>
      <Combobox.Icon />
    </Combobox.Trigger>
    <Combobox.Clear />
    <Combobox.Value>
      <Combobox.Chips>
        <Combobox.Chip>
          <Combobox.ChipRemove />
        </Combobox.Chip>
      </Combobox.Chips>
    </Combobox.Value>
  </Combobox.InputGroup>
  <Combobox.Portal>
    <Combobox.Backdrop />
    <Combobox.Positioner>
      <Combobox.Popup>
        <Combobox.Arrow />
        <Combobox.Status />
        <Combobox.Empty />
        <Combobox.List>
          <Combobox.Row>
            <Combobox.Item>
              <Combobox.ItemIndicator />
            </Combobox.Item>
          </Combobox.Row>
          <Combobox.Separator />
          <Combobox.Group>
            <Combobox.GroupLabel />
            <Combobox.Collection />
          </Combobox.Group>
        </Combobox.List>
      </Combobox.Popup>
    </Combobox.Positioner>
  </Combobox.Portal>
</Combobox.Root>;
```

| Part                                     | Renders                    | Purpose                                                                                                                                                         | Optional?                                                                                      |
| :--------------------------------------- | :------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------- |
| `Combobox.Root`                          | no element                 | Groups all parts; owns `value`/`inputValue`/`open` state and the hidden form input(s)                                                                           | required                                                                                       |
| `Combobox.Label`                         | `<div>`                    | Accessible label auto-associated with the combobox trigger, for the input-inside-popup pattern                                                                  | yes; use `<label>`/`Field.Label` when the input is outside                                     |
| `Combobox.Value`                         | no element                 | The current value; function child renders selected value(s) (used for chips)                                                                                    | yes                                                                                            |
| `Combobox.Input`                         | `<input>`                  | The text input that filters the list (the ARIA combobox)                                                                                                        | required somewhere ([#4086](https://github.com/mui/base-ui/issues/4086))                       |
| `Combobox.InputGroup`                    | `<div>`                    | One styleable container for input + controls across selection modes; becomes the default positioning anchor ([#3745](https://github.com/mui/base-ui/pull/3745)) | yes                                                                                            |
| `Combobox.Trigger`                       | `<button>`                 | A button that opens the popup                                                                                                                                   | yes                                                                                            |
| `Combobox.Icon`                          | `<span>`                   | Icon indicating the trigger opens a popup                                                                                                                       | yes                                                                                            |
| `Combobox.Clear`                         | `<button>`                 | Clears the value; mounts only while a value exists; not tabbable by design ([#3630](https://github.com/mui/base-ui/issues/3630))                                | yes                                                                                            |
| `Combobox.Chips` / `Chip` / `ChipRemove` | `<div>`/`<div>`/`<button>` | Tokenized display of multiple selections; `Chips` takes `role="toolbar"` while chips exist ([#3647](https://github.com/mui/base-ui/pull/3647))                  | yes (`multiple` only)                                                                          |
| `Combobox.Portal`                        | `<div>`                    | Moves the popup subtree to `<body>` (or `container`)                                                                                                            | required for popups ([#1222](https://github.com/mui/base-ui/pull/1222)); omit in `inline` mode |
| `Combobox.Backdrop`                      | `<div>`                    | Overlay beneath the popup                                                                                                                                       | yes                                                                                            |
| `Combobox.Positioner`                    | `<div>`                    | Positions the popup against the trigger/InputGroup                                                                                                              | required for popups                                                                            |
| `Combobox.Popup`                         | `<div>`                    | Container for the list; `role="presentation"`, or `role="dialog"` when the input is inside ([#3213](https://github.com/mui/base-ui/pull/3213))                  | required for popups                                                                            |
| `Combobox.Arrow`                         | `<div>`                    | Pointer element positioned against the anchor                                                                                                                   | yes                                                                                            |
| `Combobox.Status`                        | `<div>`                    | Polite live region for async list status; must stay mounted, so conditionally render its _children_                                                             | yes                                                                                            |
| `Combobox.Empty`                         | `<div>`                    | Renders children only when the filtered list is empty; polite live region; requires `items`                                                                     | yes                                                                                            |
| `Combobox.List`                          | `<div>`                    | The `role="listbox"` container; function child renders each filtered item                                                                                       | required                                                                                       |
| `Combobox.Row`                           | `<div>`                    | A single row of items in `grid` mode                                                                                                                            | `grid` only                                                                                    |
| `Combobox.Item`                          | `<div>`                    | `role="option"`; `React.memo`-wrapped for filtering performance                                                                                                 | required                                                                                       |
| `Combobox.ItemIndicator`                 | `<span>`                   | Indicates whether the item is selected                                                                                                                          | yes                                                                                            |
| `Combobox.Group` / `GroupLabel`          | `<div>`                    | Groups related items with an auto-associated label                                                                                                              | yes                                                                                            |
| `Combobox.Collection`                    | no element                 | Renders filtered items when a wrapper sits between `List` and the items (pass a function child to `List` for flat lists)                                        | yes                                                                                            |
| `Combobox.Separator`                     | `<div>`                    | Re-exports the standalone `Separator`                                                                                                                           | yes                                                                                            |

Non-element exports: `Combobox.useFilter` (collator matching: `contains`/`startsWith`/`endsWith`) and `Combobox.useFilteredItems` (reads the internally filtered items inside `Root`). Invisible machinery to know about: a visually-hidden `<input>` carries the serialized value (one per value in `multiple` mode; it can confound DOM-position-dependent CSS and drag-and-drop libs, [#3019](https://github.com/mui/base-ui/issues/3019)); while open + `modal`, hidden Dismiss buttons render around the popup as an AT escape hatch ([#4084](https://github.com/mui/base-ui/pull/4084)); with the input outside the popup, the rest of the page, including the Trigger, is made inert while open.

## Decision log

- **2024**: [#222](https://github.com/mui/base-ui/issues/222) specs Combobox as the closer of 7 Base UI issues and heir to 6 Material UI Autocomplete lessons; performance named the top risk (Material UI's Autocomplete took around 1,000 hours of work).
- **2025-09 (beta.3)**: [#2105](https://github.com/mui/base-ui/pull/2105) ships Combobox + Autocomplete on one internal engine with two public contracts; FilterableMenu previewed and deferred; grid/creatable/virtualized demos from day one.
- **2025-09**: `autoHighlight` opt-in ([#2668](https://github.com/mui/base-ui/pull/2668)); input value derived from `value`/`defaultValue` on first mount ([#2680](https://github.com/mui/base-ui/pull/2680)); **beta.4, breaking**: `cols` → `grid`, columns inferred from rendered `Row`s ([#2683](https://github.com/mui/base-ui/pull/2683)).
- **2025-10 / 2025-11**: the searchable-select pattern gets its own ARIA shape: Trigger `role="combobox"` ([#2973](https://github.com/mui/base-ui/pull/2973)), popup `role="dialog"` ([#3213](https://github.com/mui/base-ui/pull/3213)); `filteredItems` makes external filtering first-class ([#3068](https://github.com/mui/base-ui/pull/3068)); drag-to-select parity ([#3167](https://github.com/mui/base-ui/pull/3167)).
- **2025-12 / 2026-01**: `loopFocus` ([#3592](https://github.com/mui/base-ui/pull/3592)); `role="toolbar"` on Chips for NVDA ([#3647](https://github.com/mui/base-ui/pull/3647)); `useFilteredItems` hook ([#3732](https://github.com/mui/base-ui/pull/3732)); **value survives `items` changes**, matching native `<select>` retention and unblocking paginated async ([#3824](https://github.com/mui/base-ui/pull/3824)).
- **2026-02 / 2026-03**: `input-press` open reason ([#4015](https://github.com/mui/base-ui/pull/4015)); `InputGroup` part as the one styleable field container and default anchor ([#3745](https://github.com/mui/base-ui/pull/3745)); hidden Dismiss buttons + modal focus-trap rework ([#4084](https://github.com/mui/base-ui/pull/4084)).
- **2026-04 → 2026-06**: initial live-region announcement fix ([#4286](https://github.com/mui/base-ui/pull/4286)); iOS viewport settling delay ([#4351](https://github.com/mui/base-ui/pull/4351)); per-keystroke re-render elimination ([#4964](https://github.com/mui/base-ui/pull/4964)); grouped `limit` fix ([#5086](https://github.com/mui/base-ui/pull/5086)); `inline`+`open` requirement documented ([#5069](https://github.com/mui/base-ui/pull/5069)).
- **Standing decisions**: Clear stays non-tabbable ([#3630](https://github.com/mui/base-ui/issues/3630), not-planned); multiple+filtered close stays for now ([#3181](https://github.com/mui/base-ui/issues/3181), open); no input-less combobox ([#4086](https://github.com/mui/base-ui/issues/4086)); no trees ([#2695](https://github.com/mui/base-ui/issues/2695), [#4489](https://github.com/mui/base-ui/issues/4489)).

## Known issues & open questions

- [#4657](https://github.com/mui/base-ui/issues/4657): passing `index` to Item breaks hover highlight (open; affects virtualized compositions).
- [#3181](https://github.com/mui/base-ui/issues/3181): multiple+filtered close-on-select behavior debated (open; we are open to changing the behavior).
- [#3227](https://github.com/mui/base-ui/issues/3227): `--available-height` vs the iOS virtual keyboard (open).
- [#4938](https://github.com/mui/base-ui/issues/4938): clearing the value in the input-inside-popup pattern (open, has workaround).
- [#4188](https://github.com/mui/base-ui/issues/4188): `autoHighlight: 'always'` typing/docs gap (open).
- [#3559](https://github.com/mui/base-ui/issues/3559): Suspense-first async support (open, unplanned).
- [#2991](https://github.com/mui/base-ui/issues/2991): mobile popup-as-aside layout bug (open).
- Open docs feedback: inline examples ([#3966](https://github.com/mui/base-ui/issues/3966)), custom-value rendering ([#2759](https://github.com/mui/base-ui/issues/2759)), a Tab-to-select question ([#2894](https://github.com/mui/base-ui/issues/2894)), and async pagination guidance ([#3719](https://github.com/mui/base-ui/issues/3719)).
