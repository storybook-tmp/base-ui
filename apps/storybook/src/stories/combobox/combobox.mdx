# Combobox

{/* BEGIN: when-to-use */}

## When to use

- Choosing predefined value(s) when the item count is sufficiently large to warrant filtering (the same guidance appears on the Select page).
- Multiple selection with tokenized display: the `Chips` sub-anatomy exists for this (see Multiple select in the docs).
- Async/remote item search with selection state: `Status`/`Empty` live regions plus the recommended `items`/`filteredItems` split ([#2677](https://github.com/mui/base-ui/issues/2677), [#3818](https://github.com/mui/base-ui/issues/3818)).
- A searchable select popup (input _inside_ the popup, trigger as the form control); roles re-arrange automatically ([#2973](https://github.com/mui/base-ui/pull/2973), [#3213](https://github.com/mui/base-ui/pull/3213)).
- Filterable pickers embedded in a Dialog or rendered in-flow via `inline` ([#5069](https://github.com/mui/base-ui/pull/5069)).
- Grid layouts (emoji-picker-style) via `grid` + `Row` ([#2683](https://github.com/mui/base-ui/pull/2683)); creatable entries via a filter-miss dialog (see Creatable entries below); 1,000+ items via `virtualized`.

## When not to use

The short version for the three listbox-driven pickers: _free-form text → Autocomplete; visible filter input over a fixed set → Combobox; button + predefined values → Select; popup that performs actions → Menu._

- For free-form text (search boxes, novel tags), use [Autocomplete](?path=/docs/form-inputs-autocomplete--docs), because Combobox does not allow free-form text input. If you are fighting the input resetting to the selected value on close, you are in the wrong component ([#2677](https://github.com/mui/base-ui/issues/2677)).
- When no text input is rendered, use [Select](?path=/docs/form-inputs-select--docs), because an input-less Combobox is explicitly unsupported and loses listbox accessibility such as typeahead ([#4086](https://github.com/mui/base-ui/issues/4086)). The one supported exception: composing `Trigger`+`Value`+`Clear` without an input as a clearable-select recipe ([#2734](https://github.com/mui/base-ui/issues/2734), a known gray area).
- For a popup of _actions_ rather than a persisted value, use Menu. A filterable menu was deferred from [#2105](https://github.com/mui/base-ui/pull/2105) and remains open demand ([#4157](https://github.com/mui/base-ui/issues/4157)).
- For hierarchical/tree selection or select-all rows, use something else: trees are out of Combobox's scope ([#2695](https://github.com/mui/base-ui/issues/2695), [#4489](https://github.com/mui/base-ui/issues/4489)) and a listbox may only contain options ([#4927](https://github.com/mui/base-ui/issues/4927)).
- For very small, static option sets, prefer [Select](?path=/docs/form-inputs-select--docs) or a radio group; filtering overhead buys nothing there (the inverse of the item-count guideline above; there is no official numeric threshold).

## Anatomy

```tsx
import { Combobox } from '@base-ui/react/combobox';

<Combobox.Root>
  <Combobox.Label />
  <Combobox.InputGroup>
    <Combobox.Input />
    <Combobox.Trigger>
      <Combobox.Icon />
    </Combobox.Trigger>
    <Combobox.Clear />
    <Combobox.Value>
      <Combobox.Chips>
        <Combobox.Chip>
          <Combobox.ChipRemove />
        </Combobox.Chip>
      </Combobox.Chips>
    </Combobox.Value>
  </Combobox.InputGroup>
  <Combobox.Portal>
    <Combobox.Backdrop />
    <Combobox.Positioner>
      <Combobox.Popup>
        <Combobox.Arrow />
        <Combobox.Status />
        <Combobox.Empty />
        <Combobox.List>
          <Combobox.Row>
            <Combobox.Item>
              <Combobox.ItemIndicator />
            </Combobox.Item>
          </Combobox.Row>
          <Combobox.Separator />
          <Combobox.Group>
            <Combobox.GroupLabel />
            <Combobox.Collection />
          </Combobox.Group>
        </Combobox.List>
      </Combobox.Popup>
    </Combobox.Positioner>
  </Combobox.Portal>
</Combobox.Root>;
```

| Part                                     | Renders                    | Purpose                                                                                                                                                         | Optional?                                                                                      |
| :--------------------------------------- | :------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------- |
| `Combobox.Root`                          | no element                 | Groups all parts; owns `value`/`inputValue`/`open` state and the hidden form input(s)                                                                           | required                                                                                       |
| `Combobox.Label`                         | `<div>`                    | Accessible label auto-associated with the combobox trigger, for the input-inside-popup pattern                                                                  | yes; use `<label>`/`Field.Label` when the input is outside                                     |
| `Combobox.Value`                         | no element                 | The current value; function child renders selected value(s) (used for chips)                                                                                    | yes                                                                                            |
| `Combobox.Input`                         | `<input>`                  | The text input that filters the list (the ARIA combobox)                                                                                                        | required somewhere ([#4086](https://github.com/mui/base-ui/issues/4086))                       |
| `Combobox.InputGroup`                    | `<div>`                    | One styleable container for input + controls across selection modes; becomes the default positioning anchor ([#3745](https://github.com/mui/base-ui/pull/3745)) | yes                                                                                            |
| `Combobox.Trigger`                       | `<button>`                 | A button that opens the popup                                                                                                                                   | yes                                                                                            |
| `Combobox.Icon`                          | `<span>`                   | Icon indicating the trigger opens a popup                                                                                                                       | yes                                                                                            |
| `Combobox.Clear`                         | `<button>`                 | Clears the value; mounts only while a value exists; not tabbable by design ([#3630](https://github.com/mui/base-ui/issues/3630))                                | yes                                                                                            |
| `Combobox.Chips` / `Chip` / `ChipRemove` | `<div>`/`<div>`/`<button>` | Tokenized display of multiple selections; `Chips` takes `role="toolbar"` while chips exist ([#3647](https://github.com/mui/base-ui/pull/3647))                  | yes (`multiple` only)                                                                          |
| `Combobox.Portal`                        | `<div>`                    | Moves the popup subtree to `<body>` (or `container`)                                                                                                            | required for popups ([#1222](https://github.com/mui/base-ui/pull/1222)); omit in `inline` mode |
| `Combobox.Backdrop`                      | `<div>`                    | Overlay beneath the popup                                                                                                                                       | yes                                                                                            |
| `Combobox.Positioner`                    | `<div>`                    | Positions the popup against the trigger/InputGroup                                                                                                              | required for popups                                                                            |
| `Combobox.Popup`                         | `<div>`                    | Container for the list; `role="presentation"`, or `role="dialog"` when the input is inside ([#3213](https://github.com/mui/base-ui/pull/3213))                  | required for popups                                                                            |
| `Combobox.Arrow`                         | `<div>`                    | Pointer element positioned against the anchor                                                                                                                   | yes                                                                                            |
| `Combobox.Status`                        | `<div>`                    | Polite live region for async list status; must stay mounted, so conditionally render its _children_                                                             | yes                                                                                            |
| `Combobox.Empty`                         | `<div>`                    | Renders children only when the filtered list is empty; polite live region; requires `items`                                                                     | yes                                                                                            |
| `Combobox.List`                          | `<div>`                    | The `role="listbox"` container; function child renders each filtered item                                                                                       | required                                                                                       |
| `Combobox.Row`                           | `<div>`                    | A single row of items in `grid` mode                                                                                                                            | `grid` only                                                                                    |
| `Combobox.Item`                          | `<div>`                    | `role="option"`; `React.memo`-wrapped for filtering performance                                                                                                 | required                                                                                       |
| `Combobox.ItemIndicator`                 | `<span>`                   | Indicates whether the item is selected                                                                                                                          | yes                                                                                            |
| `Combobox.Group` / `GroupLabel`          | `<div>`                    | Groups related items with an auto-associated label                                                                                                              | yes                                                                                            |
| `Combobox.Collection`                    | no element                 | Renders filtered items when a wrapper sits between `List` and the items (pass a function child to `List` for flat lists)                                        | yes                                                                                            |
| `Combobox.Separator`                     | `<div>`                    | Re-exports the standalone `Separator`                                                                                                                           | yes                                                                                            |

Non-element exports: `Combobox.useFilter` (collator matching: `contains`/`startsWith`/`endsWith`) and `Combobox.useFilteredItems` (reads the internally filtered items inside `Root`). Invisible machinery to know about: a visually-hidden `<input>` carries the serialized value (one per value in `multiple` mode; it can confound DOM-position-dependent CSS and drag-and-drop libs, [#3019](https://github.com/mui/base-ui/issues/3019)); while open + `modal`, hidden Dismiss buttons render around the popup as an AT escape hatch ([#4084](https://github.com/mui/base-ui/pull/4084)); with the input outside the popup, the rest of the page, including the Trigger, is made inert while open.

## Related

- For a dropdown of predefined values **without typing**, use [Select](?path=/docs/form-inputs-select--docs): Combobox is a filterable Select.
- For **free-form text** with suggestions, use [Autocomplete](?path=/docs/form-inputs-autocomplete--docs): same engine, but the text _is_ the value.
- For a popup of **actions**, use Menu; a filterable menu remains open demand ([#4157](https://github.com/mui/base-ui/issues/4157)).
- To add labels, descriptions, and validation, wrap in [Field](?path=/docs/form-inputs-field--docs) inside a [Form](?path=/docs/form-inputs-form--docs).
