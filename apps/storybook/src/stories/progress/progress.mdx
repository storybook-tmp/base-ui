# Progress

{/* BEGIN: when-to-use */}

## When to use

- Long-running async tasks where completion is knowable or trackable: uploads, downloads, exports, multi-step processing (the docs hero simulates "Export data").
- A numeric position within an arbitrary range that must drive ARIA, fill, and text consistently, e.g. "$30 of $100 budget" via `format`.
- Work is happening but the duration is unknown: indeterminate mode is our accessible answer to showing a busy state.

## When not to use

- For a **bounded measurement with no notion of "done"** (disk usage, battery level), use [Meter](?path=/docs/status-display-meter--docs), because the APG meter pattern explicitly excludes "progress, such as loading or percent completion of a task".
- If your team wants **zero custom ARIA** and accepts native quirks, native `<progress>` remains a documented alternative. We declined to adopt it, citing cross-browser/screen-reader inconsistencies and parity with Radix and React Aria ([#4558](https://github.com/mui/base-ui/issues/4558)).

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Progress } from '@base-ui/react/progress';

<Progress.Root>
  <Progress.Label />
  <Progress.Value />
  <Progress.Track>
    <Progress.Indicator />
  </Progress.Track>
</Progress.Root>;
```

| Part                 | Renders                      | Purpose                                                      | Optional? |
| :------------------- | :--------------------------- | :----------------------------------------------------------- | :-------- |
| `Progress.Root`      | `<div role="progressbar">`   | Owns all `aria-value*` attributes and context                | required  |
| `Progress.Label`     | `<span role="presentation">` | Visible label, auto-wired to Root's `aria-labelledby`        | yes       |
| `Progress.Track`     | `<div>`                      | Positioning/overflow context for the indicator               | yes       |
| `Progress.Indicator` | `<div>`                      | The fill; the only part receiving inline style (`width: N%`) | yes       |
| `Progress.Value`     | `<span aria-hidden>`         | Visual mirror of the formatted value                         | yes       |

Root also renders a visually hidden `<span role="presentation">` sibling, the NVDA workaround ([#4200](https://github.com/mui/base-ui/pull/4200)). It is not a stylable part.
