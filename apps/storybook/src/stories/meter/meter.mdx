# Meter

{/* BEGIN: when-to-use */}

## When to use

- Storage/disk usage, the subject of the hero demo.
- Battery level, the example subject of the component's test suite.
- Any **static measurement of a known, bounded quantity at a point in time**: gauges, capacity indicators, fuel levels, scores within a range.

## When not to use

- For a **task moving toward completion**, use [Progress](?path=/docs/status-display-progress--docs), because the APG meter pattern explicitly says meters should not "indicate progress, such as loading or percent completion of a task".
- When the amount is **unknown**: Meter is never indeterminate by design; `value` is a required, always-numeric prop. For unknown-duration, still-working states, use Progress's indeterminate mode.
- For an **interactive** value the user can change, use Slider. Meter has no focusability or key handling; it is read-only by construction.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

```tsx
import { Meter } from '@base-ui/react/meter';

<Meter.Root>
  <Meter.Label />
  <Meter.Value />
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
</Meter.Root>;
```

| Part              | Renders              | Purpose                                                                    | Optional? |
| :---------------- | :------------------- | :------------------------------------------------------------------------- | :-------- |
| `Meter.Root`      | `<div role="meter">` | Owns `aria-value*`/`aria-labelledby`, computes formatted/percentage values | required  |
| `Meter.Label`     | `<span>`             | Visible label; self-registers into Root's `aria-labelledby`                | yes       |
| `Meter.Track`     | `<div>`              | Pure layout container representing the range                               | yes       |
| `Meter.Indicator` | `<div>`              | The fill; the only part receiving inline style (`width: N%`)               | yes       |
| `Meter.Value`     | `<span aria-hidden>` | Visual mirror of the formatted value                                       | yes       |

All parts throw outside `<Meter.Root>`. Root also renders the same visually hidden NVDA-workaround span as Progress ([#4184](https://github.com/mui/base-ui/issues/4184)).

{/* END: anatomy */}

## Related

- To display **task completion** (including unknown-duration work), use [Progress](?path=/docs/status-display-progress--docs).
- To let users **set** a value in a range, use Slider (interactive and keyboard-operable, which Meter by design is not).
